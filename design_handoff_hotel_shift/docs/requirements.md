# ホテル シフト管理アプリ　要件定義（たたき台 v0.2）

2026年10月20日　／　対象：BHJ・BHKK・MAHB・MAHT・MAHNM
※第1回・第2回フォームの回答をもとに作成。【要確認】は残っている確認事項です。

## 1. 施設とシフト枠

| 施設 | 標準枠 | 時間指定 |
| --- | --- | --- |
| BHJ | 朝 8:00–16:00 ／ 夕 14:00–22:00 ／ 夜 22:00–翌8:00 | あり |
| BHKK | 朝 8:00–16:00 ／ 夕 14:00–22:00 ／ 夜 22:00–翌8:00 | あり |
| MAHB | 朝 10:00–19:00 ／ 夕 13:00–22:00 ／ 夜 22:00–翌8:00 | あり |
| MAHT | 基本 10:00–18:00（1枠のみ） | あり |
| MAHNM | 朝 8:00–16:00 ／ 夕 14:00–22:00 ／ 夜 22:00–翌8:00 | あり |

- 枠の名前・時刻・数は、施設ごとに管理者が設定できる。
- 時間指定（例：8:00–14:00）は、どの施設でも入力できる。
- 最低人数：基本は各枠1名。イレギュラーに備え、枠ごとに2〜3名まで設定できるようにする。
  - 【要確認】最低人数を変えるのは「枠の標準設定」か「特定の日だけ」か。両方できるようにする想定です。

## 2. スタッフの所属（兼任）

- BHJ・MAHT・MAHBは施設が近く、スタッフが兼任している。日によって勤務施設が変わる。
- スタッフは**複数の施設に所属できる**。そのうち1つを**主な所属施設**として登録する。
- シフトは「日付・時間・**勤務施設**」で登録する。
- **希望には施設を指定しない**。どの施設で勤務するかは管理者が決める。
- 日次調整の画面には、その施設に所属する兼任者も表示する。他の施設に配置済みの人には「BHJで勤務」などと表示する。
- 同じ人が同じ時間に複数の施設に入っていないかを、施設をまたいでチェックする。

## 3. 希望提出

- 提出期限：**前月15日**（例：11月分は10月15日まで）。
- 期限までは何度でも変更・再提出できる。期限後はスタッフ側では変更できない。
- 期限後の提出・変更は、**管理者がスタッフごとに期限を延長**して受け付ける。
- 提出の催促メールは送らない。管理者が画面で未提出者を確認する。

## 4. 確定と確定後の変更

- 管理者が施設ごと、または全施設まとめて「確定して公開」する。
- 確定後の変更は**管理者が直接行い、本人にメールで通知**する。
- スタッフからの変更申請や、スタッフ同士の交代の機能は設けない。

## 5. 自動チェック（警告のみ・保存は止めない）

| チェック | 内容 |
| --- | --- |
| 欠員 | 枠の配置人数が最低人数を下回る |
| 勤務間インターバル | 前の勤務の終わりから次の勤務の始まりまでが**8時間未満** |
| 重複 | 同じ人が同じ時間に複数の施設で配置されている |

- チェックは施設をまたいで行う（例：前日BHJで22:00–翌8:00 → 当日MAHTで10:00開始は、間隔2時間でNG）。
- **夜勤明けの朝勤NGは廃止**し、インターバルのチェックに統一する。

## 6. 給与・人件費

- 締め日：**月末締め**。
- 深夜割増：**22:00–5:00、25%**。
- 休憩：

| 勤務 | 休憩 |
| --- | --- |
| 夜勤 | 3時間 |
| 日勤（朝・夕・時間指定）6時間以上 | 45分 |
| 日勤 8時間以上 | 60分 |

  - 【要確認】ちょうど6時間の勤務も45分休憩にするか。労働基準法では「6時間を超える場合に45分以上」が最低ラインです。

- 交通費の上限（1日あたり）：

| 勤続 | 上限 |
| --- | --- |
| 入社から6か月目の給与月まで | 1,000円 |
| 7か月目の給与月から | 1,200円 |
| 勤続18か月以上、かつ累計216日以上の勤務 | 1,500円 |

  - スタッフごとに「入社日」を登録する。勤続月数と累計勤務日数は、アプリが自動で計算する。
  - 【要確認】「※」の補足の内容。
  - 【要確認】「累計216日」はこのアプリでの勤務日数だけで数えてよいか。oplusでの過去実績は引き継がないため、入社済みのスタッフは初期値を手入力する想定です。

- 人件費は、兼任者の分も**主な所属施設にまとめて計上**する。
- 時給・人件費は、すべての管理者が見られる。

## 7. 権限とログイン

| 役割 | できること |
| --- | --- |
| スタッフ | 希望の提出、所属するすべての施設の確定シフトの閲覧 |
| 管理者（1種類） | 全施設のシフト作成・確定、期限の延長、スタッフ設定、人件費・希望採用率の閲覧 |

- ログイン：メールアドレスにログイン用リンクを送る方式（パスワードなし）。
- スタッフの登録・退職時の停止は、管理者が行う。

## 8. 通知（メールのみ）

| タイミング | 宛先 |
| --- | --- |
| シフト確定・公開 | 対象施設に所属するスタッフ |
| 確定後の変更 | 変更された本人 |
| 期限の延長 | 対象のスタッフ |

## 9. 移行と連携

- 今はoplusで管理している。他のシステムとの連携は不要。
- **データ移行はしない**。スタッフ・施設・枠は手入力で登録する。
- 登録時に必要な項目：氏名、メールアドレス、所属施設（主な所属を含む）、時給、交通費の金額、入社日、累計勤務日数の初期値。

## 10. 技術構成（想定案）

- 画面：Next.js（スマホとPCの両方に対応。ホーム画面に追加して使えるPWA）。
- データベース・認証：Supabase（東京リージョン）。管理者以外は時給を読めないよう、データベース側で権限を制限する（RLS）。
- メール送信：ログイン用リンクはSupabaseの認証機能で送る。通知はメール送信サービスを使う。
- 環境：テスト用（ステージング）と本番の2つ。毎日バックアップを取る。

## モックに反映が必要な点

1. 施設ごとのシフト枠（MAHTは1枠、MAHBの時刻）と、最低人数の設定
2. 兼任：複数の施設に所属、主な所属施設、他施設に配置済みであることの表示
3. チェックの変更：夜勤明けの朝勤NGをやめ、8時間のインターバルと施設をまたぐ重複のチェックに置き換える
4. 給与計算：夜勤の休憩3時間、勤続に応じた交通費の上限、兼任者の人件費を主な所属施設に計上
5. 管理者による提出期限の個別延長
